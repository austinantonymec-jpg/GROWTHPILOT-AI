# Evaluation method

`scripts/run_simulation.py` uses a seeded synthetic 100-session experiment. It compares a static baseline against an agent-assisted flow: baseline conversion is sampled at 31%; relevant accepted bundles add 16–36% to order value; a small incremental conversion is permitted in the agent flow. Discount cost is calculated from simulated agent revenue.

Results therefore arise from the model, not from static dashboard claims. Change the seed or session count to explore variance.
